# Results Directory

This directory stores small, committed, deterministic outputs of the RabindricGPT pipeline:

- `preflight_report.json`: Verification report generated by `scripts/00_preflight.py` detailing code fingerprint, platform info, and Level P0–P6 check results.
- `g1_audit.json` / `g1_audit.md`: Gate G1 data audit report generated by `scripts/04_audit.py` verifying Bengali script ratio (>=80%), bytes/character ratio, and absence of PUA characters.
- `g2_report.json`: Gate G2 tokenizer validation report generated by `scripts/06_tokenizer_tests.py` verifying roundtrip losslessness, token-to-byte boundaries, and fertility metrics.
- `params.json` / `params.md`: Exact non-embedding and total parameter counts across all model sizes (10M, 25M, 50M, 100M) and all 6 tokenizers generated by `scripts/08_model_param_report.py`.
- `pilot.json`: GPU throughput, MFU, and burn-rate benchmark report generated by `scripts/09_pilot.py`.
- `run_matrix.csv`: Canonical execution matrix defining all 38 planned training and adaptation runs generated by `scripts/10_make_run_matrix.py`.
- `ledger.md`: Compute unit spend tracking and aggregated run ledger generated by `scripts/14_update_ledger.py`.
- `eval_<run_id>.json`: Evaluation report for individual runs containing exact BPC, BPB, bootstrap confidence intervals, and generation checks from `scripts/12_final_eval.py`.
- `fits.json`: Power-law scaling curve fits ($A \cdot N^{-\alpha}$) for each tokenizer generated by `scripts/13_fit_and_plot.py`.
- `hypotheses.json`: Formal evaluation outcomes and decision verdicts for research hypotheses H1 through H6 generated by `scripts/13_fit_and_plot.py`.
- `figures/`: Publication-quality scaling plots (`scaling_curves.png`, `bpb_vs_compression.png`, `adaptation_trajectories.png`).
- `tables/`: GitHub-flavored Markdown tables with explicit run-ID provenance (`main_summary_table.md`).
